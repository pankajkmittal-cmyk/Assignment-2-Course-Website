Course Overview

This course introduces the core concepts of modern operating systems. Students will learn how an operating system manages system resources, handles processes, schedules tasks, controls memory, and manages filesystems. By the end of this course, you will understand the hidden layer that connects software applications to computer hardware.

Weekly Schedule

Week Topic Core Focus
Week 1-2 Introduction to OS & System Structures Monolithic vs. Microkernels, System Calls, Interrupts
Week 3-4 Process Management & Threads PCB, Context Switching, Inter-process Communication
Week 5-6 CPU Scheduling Algorithms FCFS, SJF, Round Robin, Priority Scheduling
Week 7-8 Process Synchronization & Deadlocks Semaphores, Critical Section, Banker's Algorithm
Week 9-10 Memory Management Paging, Segmentation, Virtual Memory, Page Replacement
Week 11-12 Storage & File Systems Disk Scheduling (SCAN, LOOK), File Allocation Methods
